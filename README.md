## 📌 Project Description
This project is part of the ICS344 Information Security course.  
The objective is to analyze and exploit vulnerabilities in the DVSA (Damn Vulnerable Serverless Application) environment, then apply appropriate fixes and verify the security improvements.

---

## 🎯 Project Objectives
- Identify 10 vulnerabilities  
- Exploit each vulnerability  
- Analyze the root cause  
- Apply fixes and mitigation strategies  
- Verify that the vulnerabilities are resolved  

---
